# Инструкция для AI-агентов

[ilyathefrog.ru](https://ilyathefrog.ru/) — двуязычная визитка на Astro. GitHub Actions собирает статический сайт и публикует `dist/` на GitHub Pages. Регистрация и DNS домена управляются в Beget.

## Контент

- `src/content/profiles/ru.md` и `en.md` — тексты русской и английской страниц. Биография — в теле Markdown, подписи и тексты карточек — в `copy` в начале файла.
- Публикации — по одному файлу в `src/content/publications/`. Скопируй структуру любой записи: `date` в формате YYYY-MM-DD, `url`, `publisher.ru` и `publisher.en`, `title.ru` и `title.en`. Сборка сортирует публикации от новых к старым.
- Выступления — по одному файлу в `src/content/talks/`. Используй следующий `order`, оба заголовка и все действующие ссылки с подписями на двух языках.
- Общие ссылки и дата `updated` лежат в `src/content/site/site.md`. При контентном изменении обнови дату там.
- Шаблон обеих языковых версий — `src/components/Home.astro`, стили и изображения — в `public/`.

Обновляй оба языка. У публикаций используй принятое название издания для каждого языка. Astro проверяет наличие обоих заголовков, дату и URL при сборке. `/index.md`, `/llms.txt` и `/sitemap.xml` генерируются из общего контента.

## Проверка

- Выполни `npm run build` и `npm test`.
- Запусти `npm run preview` и открой сайт в браузере. Проверь ссылки RU/EN и изменённый контент на обеих страницах.

## Git

- Пуш в `main` — деплой на прод. Не коммитить и не пушить без явной просьбы владельца.
- Сообщения коммитов — краткие, на английском, в духе `Add new Habr publication`.
