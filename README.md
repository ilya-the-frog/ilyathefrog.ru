# ilyathefrog.ru

Моя личная визитка: [ilyathefrog.ru](https://ilyathefrog.ru/).

Личная визитка на Astro. GitHub Actions собирает русский и английский HTML из Markdown и публикует `dist/` на GitHub Pages.

Для меня это второе возвращение в разработку после [Kirkorov](https://t.me/travelasproduct/73): теперь уже с личным ноутбуком, своим сайтом и AI-инструментами под рукой.

## Контент

- `src/content/profiles/ru.md` и `en.md` — тексты страниц. Биография находится в основном тексте Markdown, остальные подписи — в блоке данных в начале файла.
- `src/content/publications/` — один Markdown-файл на публикацию. В нём дата, ссылка, издатель и заголовок на двух языках. Список сортируется по дате.
- `src/content/talks/` — один Markdown-файл на выступление, с порядковым номером и ссылками на площадки.
- `src/content/site/site.md` — общие ссылки и дата обновления. При изменении контента обнови поле `updated`.
- `src/components/Home.astro` — общий HTML-шаблон. Стили и изображения в `public/`.

Сборка создаёт русскую страницу `/`, английскую `/en/`, полный профиль для агентов `/index.md`, `/llms.txt` и `/sitemap.xml`. Переключатель языка работает обычными ссылками. У каждой версии собственный адрес, доступный без JavaScript.

## Разработка

Нужен Node.js 24. Установка и проверка сборки:

```sh
npm ci
npm run build
npm test
npm run preview
```

Для разработки с автообновлением запусти `npm run dev`.

## Деплой

GitHub Pages размещает готовые статические файлы, поэтому отдельный хостинг для сайта не нужен. Свой домен нужен для адреса `ilyathefrog.ru`. Он зарегистрирован в [Beget](https://beget.com/p2494612), там же управляются его DNS-записи. Без своего домена можно использовать стандартный адрес на `github.io`.

После push в `main` GitHub Actions проверяет сборку и публикует `dist/`. В GitHub Pages источником должен быть выбран **GitHub Actions**.

Markdown доступен по адресу `/index.md`, ссылка на него есть в HTML. Корневой URL отдаёт HTML при любом `Accept`.
